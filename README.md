# Corps Command: Heavy Duty

A phone-first 3D engineering game. You command U.S. Army Corps of Engineers rigs on disaster-response jobs.

Play: https://xz64uj777.github.io/grokarmynew/

## Missions

- **Levee Breach:** Push rock into the gap with the dozer and drop concrete barriers with the crane before the river floods the town.
- **Forward Airfield:** Grade the dirt strip, lay runway matting, and light it before the cargo plane arrives.

## Garage

The amphibious dredger, heavy-lift helicopter, and dewatering pump are in the garage for later missions.

## Dev

npm ci
